# 검증 결과: 평균은 linear, 인코딩은 저장값

- 입력: test.dds, 2048×2048, BC1_UNORM_SRGB (DXGI 72).
- 수정 전 기준: Git HEAD 882dea3의 기존 linear 인코더. 중간에 작성했던 가중 최소제곱/후보 선택 버전은 비교 기준이 아님.
- 수정 전/후 모두 동일 MSVC 19.39 + CUDA 12.8 Release 설정으로 빌드 성공.
- 평균 피라미드, 타깃 생성, 기존 PCA/비가중 최소제곱 식은 유지. 가중 피팅과 linear SSE 후보 선택은 제거.
- CUDA E는 기존 --use_fast_math가 powf를 근사 __powf로 바꾸지 않도록 double pow를 사용. 전역 컴파일 옵션과 non-sRGB 경로는 유지.

## T1

CPU / SIMD / CUDA 모두 c0=0xFFFF, c1=0x0000, 원본 저장값 대비 SSE=0.
CPU/SIMD 10,000배치에서 `sRGB 인코더(linear)`와 `non-sRGB 인코더(E(linear))`의 바이트 일치도 통과.

## T2

같은 test.dds의 복사본에서 DXGI 값만 71(BC1_UNORM)로 변경하여 non-sRGB 입력을 구성. 원본 파일은 수정하지 않음.
세 backend 모두 수정 전/후 전체 DDS 바이트 차이 **0**.

## T4

스칼라/SIMD 전체 DDS 차이: 수정 전 **198바이트**, 수정 후 **126바이트**.
요청에 적힌 기존 258바이트는 이번 소스·입력·빌드 조합에서 재현되지 않았으므로 실제 측정값을 기록함.

## 실행 시간

CLI가 출력하는 mip 생성 시간. backend/버전별 워밍업 1회 후 5회 중앙값이며, 다른 측정과 동시에 실행하지 않음. 파일 입출력과 CUDA 초기 준비는 이 타이머 밖에 있음. 참고치이며 E만의 단독 비용은 아님.

| CPU | 5.3182 | 6.4083 |
| SIMD | 2.1020 | 5.1662 |
| CUDA | 0.5981 | 2.0597 |

## T3

정수 BC1 디코드 후 linear로 변환한 mip-0를 기준으로, 각 레벨의 직접 2^L box 타깃을 float64로 계산. 저장값 SSE는 E(타깃)과 디코드 저장값/255를 비교하고, linear SSE는 타깃과 L(디코드 저장값)을 비교함. 표의 SSE는 모든 유효 픽셀 RGB 오차제곱의 합.

저장값 SSE는 대부분 감소하지만 레벨 8은 증가. Linear SSE는 레벨 3, 8에서 증가. 이는 가중치나 기존 후보 보호 없이 저장값에서 피팅·selector를 고르는 요청된 목적함수의 결과이며, 모든 레벨의 오차 감소를 보장하지 않음.
